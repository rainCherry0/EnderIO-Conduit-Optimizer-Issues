# 🇬🇧 English Version

# Ender IO: Conduit Optimizer - Issue Tracker

Welcome to the public issue tracker and community repository for **Ender IO: Conduit Optimizer**!

⚠️ **Important Notice:**
The core code of this MOD is **closed-source**. This GitHub repository does not contain any game source code. It is exclusively meant for tracking **Bug Reports** and collecting **Feature Suggestions**.

---

## 📥 Downloads & Links

You can download the latest version of the MOD or check for more details here:

*   **CurseForge:** [https://www.curseforge.com/minecraft/mc-mods/ender-io-conduit-optimizer](https://www.curseforge.com/minecraft/mc-mods/ender-io-conduit-optimizer)
*   **Modrinth:** [https://modrinth.com/mod/ender-io-conduit-optimizer](https://modrinth.com/mod/ender-io-conduit-optimizer)

> Note: Ender IO: Conduit Optimizer is an unofficial add-on for Ender IO, so please **do not report issues of this mod to the original Ender IO team**. Please also **do not report them to the [EnderIO-Evolution-Issues](https://github.com/rainCherry0/EnderIO-Evolution-Issues) repository** (that one is for a different mod). Report them here instead.

---

## 🐛 How to Report a Bug or Suggest a Feature?

If you encounter crashes, incorrect conduit behavior, compatibility issues, or have a brilliant idea, please let me know via the **[Issues](https://github.com/rainCherry0/EnderIO-Conduit-Optimizer-Issues/issues)** tab!

To help me fix the issue as quickly as possible, please provide:
1. A clear description of the issue.
2. Your Minecraft version.
3. The Mod Loader and its version (Forge / NeoForge).
4. The crash report or the game log (`logs/latest.log`).
5. The version of **Ender IO** you are using **and** the version of **Ender IO: Conduit Optimizer** (both are required).
6. Whether the issue also occurs in a setup without other Ender IO add-ons (e.g., Ender IO: Evolution, More Conduits, GasConduits, Endergy), to help narrow down compatibility problems.

## 🐛 如何提交 Bug 或 功能建议？

如果你在游戏中遇到了报错、导管行为异常、兼容性问题，或者有非常棒的新想法，欢迎通过本仓库的 **[Issues](https://github.com/rainCherry0/EnderIO-Conduit-Optimizer-Issues/issues)** 页面反馈给我！

在提交 Issue 时，请尽量提供以下信息，这将大大加快修复速度：
1. 遇到的具体问题描述。
2. 你的游戏版本。
3. 使用的 Mod 加载器版本（Forge / NeoForge）。
4. 游戏崩溃日志（Crash Report）或游戏日志（`logs/latest.log`）。
5. 你正在使用的 **Ender IO 本体版本** 与 **Ender IO: Conduit Optimizer 版本**（两者都要提供）。
6. 如果可能，请确认不带其他 Ender IO 附属模组（如 Ender IO: Evolution、More Conduits、GasConduits、Endergy）时问题是否仍然出现（这有助于排查兼容性问题）。
